# Do clique no anúncio ao CRM — rascunho técnico (08/10/2026)

Rascunho da frente H do plano «100+ melhorias», montado SÓ a partir dos campos `passos` dos 8 mapas de leitura
(`scratchpad/mapa/A…H.json`, fora do repositório). Cada passo diz onde acontece (`arquivo:função`, linha da leitura de
07–08/10/2026 sobre a main `d106827`), o que é gravado e onde pode falhar. Referências: «[A3]», «[B7]» = o passo de ordem 3 do
mapa A / 7 do mapa B; «[A4-bug]» = o bug nº 4 do mapa A (posição na lista `bugs`); números altos («[A18]», «[C113]», «[G251]») = a
melhoria na numeração global do plano (cabeçalho + bugs + melhorias + perguntas de cada segmento, A→H: A18 = 7ª melhoria de A);
«[A pergunta 2]» = a pergunta aberta; «→ S-B2», «→ F11» = o item do `PLANO-100-20261008.md` que trata o ponto. O Claude escreve
depois a versão para o dono (sem código). Nada aqui foi inventado além do que os mapas registram; o que eles não confirmaram está
marcado como «não confirmado» ou «inferência».

Convenções: SP = America/Sao_Paulo; «referral» = o bloco que a Meta anexa à 1ª mensagem de um anúncio clique-para-WhatsApp
(`source_type`, `source_id`, `ctwa_clid`, `source_url`, `headline`, `body`); «[ref XXXXX]» = o código de 5 letras que o script
do site coloca no fim do texto do WhatsApp; CTWA = anúncio «Mensagem no WhatsApp» (abre o WhatsApp sem passar pelo site).

## Mapa em uma olhada

```
anúncio ──(a) site + UTMs/fbclid/gclid──► rastreio.js ──clique no wa.me──► nx_rastreio_registrar ──► [ref K7Q2P] no texto
        ──(c) CTWA (sem site) ──────────────────────────────────────────────────────────► WhatsApp abre direto (referral)
WhatsApp ──aparelho CodeWords──► nx-codewords (API do agente) ─┐
         ──número Meta Cloud ──► nx-whatsapp (webhook)        ─┴► nx_wa_entrada ► nx_lead_webhook ► nx_rastreio_atribuir (só CodeWords hoje)
                                                                  ► nx_codewords_decidir ► IA do fluxo responde (só CodeWords)
                                                                  ► nx_eventos ► automações (nx_auto_lote) ► IA das automações
painel ◄── nx_pulso / nx_cv_listar / nx_cv_ver ── atendente responde ► nx-enviar ► canal ► nx_cv_saida
anúncios ◄── nx-ciclo (Meta/Google → nx_metricas_dia, radar) ── nx-relatorio (diário/mensal no WhatsApp) ── painel Ads (nx_dados)
```

## 10. Pontos de falha que atravessam o fluxo (resumo para a versão do dono)
